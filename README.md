# Я Є. Україна 🇺🇦

Перший інтерактивний прототип спільної мапи українців. Відкрийте `index.html` у браузері або увімкніть GitHub Pages із гілки `main`, корінь `/`.

## Демо

- Адаптивний темний UI, мозаїка України, локальний вибір місця
- Створення і поширення демонстраційної картки
- Пошук за номером чи локально збереженим ім'ям
- Дані зберігаються тільки в localStorage браузера

**Це не запущений платіжний сервіс.** Немає оплати, загальної бази учасників, гарантії глобальної унікальності, точної географії чи серверної реєстрації. Контур — умовний дизайн-макет.

Перед комерційним запуском потрібні верифікована геометрія, backend із транзакційним резервуванням, платіжна інтеграція з перевіркою webhook, модерація та політика приватності.
